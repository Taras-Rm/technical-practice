# GitHub Activity CLI

GitHub Activity CLI is a simple command line application that fetches and displays the **recent public activity of a GitHub user** directly in the terminal.

## 🚀 Features

With this CLI tool, you can:

- Pass a GitHub username as a command line argument
- Fetch the user's recent public activity using the GitHub API

## 📌 Run

Run CLI application:

- Run from the command line
- Accept a GitHub username as an argument  
  Example:
  ```bash
  go run ./main.go <username>
